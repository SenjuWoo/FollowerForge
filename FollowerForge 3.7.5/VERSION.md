# FollowerForge 3.7.5

Parent: released 3.7.4 (GitHub v3.7.4, SHA 77e6b0b). The 3.7.4 snapshot is kept unchanged.

This build names the head parts it writes, and it refuses to stay quiet about the two
arrangements the game completes differently: a part restricted to another race, and a preset
from one race built as another. That second case is GitHub issue #2 — a hair record with no race
restriction is applied to every race, so a mesh modelled around one skull renders around another.
See VALIDATION.md for the records read on this machine.
